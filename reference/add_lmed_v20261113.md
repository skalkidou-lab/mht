# Add 2026-11-13 MHT exposure to a person-week skeleton

Writes every column that \`add_lmed_v20261112()\` writes. A former-use
week is \`previous3y\` in a \`prev3y\` column and \`previousany\` in a
\`prevany\` column, where \`add_lmed_v20261112()\` writes \`previous\`
in both.

## Usage

``` r
add_lmed_v20261113(
  skeleton,
  lmed,
  id_name = "lopnr",
  create_rd = TRUE,
  verbose = TRUE
)
```

## Arguments

- skeleton:

  A person-week \`data.table\` with \`id\` and \`isoyearweek\`. Weekly
  rows only, as for \`add_lmed_v20261105()\`.

- lmed:

  A \`data.table\` of dispensed prescriptions.

- id_name:

  The person identifier column of \`lmed\`.

- create_rd:

  Logical. If \`FALSE\`, writes no \`rd_approach\*\` column.

- verbose:

  Logical. If \`TRUE\`, report progress with \`message()\`.

## Value

\`invisible(skeleton)\`. Mutation is in place.

## Details

The function writes 28 \`rd_approach\*\` columns, named
\`rd_approach\<N\>\_\<variant\>\_\<rule\>\`. \`N\` is 1 to 6 or \`3b\`,
\`variant\` is \`single\` or \`multiple\`, and \`rule\` is one of the
two rules below. It writes no column named
\`rd_approach\<N\>\_\<variant\>\` without a rule.

- \`prev3y\`: an untreated week after a stop is \`previous3y\` only if
  the treated episode lasted 156 weeks or more. After a shorter episode
  it is \`exclude\`. This is the rule of \`add_lmed_v20261105()\`.

- \`prevany\`: any stop gives \`previousany\`, whatever the length of
  the episode.

The two rules differ only in the weeks after a stop from an episode
shorter than 156 weeks: \`prev3y\` gives \`exclude\` and \`prevany\`
gives \`previousany\`. In the \`single\` variant both rules set every
week from a re-initiation onward to \`exclude\`. The four-week gap
bridge runs before the rules and is the same for both.

No column holds the value \`previous\`. Each \`rd_approach\*\` column
equals the \`add_lmed_v20261112()\` column of the same name, with
\`previous\` mapped to the value of its rule. Every other column equals
the output of \`add_lmed_v20261112()\`. The function reads the two
workbooks of \`add_lmed_v20261105()\`:
\`inst/2023-mht/product_table_20261105.xlsx\` and
\`inst/2023-mht/dataDictionary20261105.xlsx\`.

## See also

[`add_lmed_v20261105`](https://skalkidou-lab.github.io/mht/reference/add_lmed_v20261105.md),
which documents the approaches.
[`add_lmed_v20261112`](https://skalkidou-lab.github.io/mht/reference/add_lmed_v20261112.md),
which writes \`previous\` in both rules. \`vignette("lmed-v20261113")\`
explains approaches 1 to 6 and the two rules.
