# Synthetic person-week skeleton

The person-week grid that \[x2023_add_lmed()\] and \[x2026_add_lmed()\]
write their exposure columns into. One row per person per ISO week, with
no payload columns: the entry points add every derived column
themselves.

## Usage

``` r
fake_skeleton_mht
```

## Format

A \[data.table::data.table\] with 5616 rows (18 persons x 312 ISO weeks)
and 2 columns:

- id:

  integer. Person identifier, 1 to 18, matching the identifier column of
  \[fake_lmed_2023\] and \[fake_lmed_2026\].

- isoyearweek:

  character. ISO year and week as \`"YYYY-WW"\`, from \`"2015-02"\` to
  \`"2020-52"\`, sorting correctly as a string.

## Source

Synthetic. Generated by \`dev/generate_fake_lmed.R\` with
\`set.seed(42)\`, from the same weekly grid as \[fake_lmed_2023\] and
\[fake_lmed_2026\]. The grid deliberately spans 312 ISO weeks (2015-W02
to 2020-W52, six ISO years) so that the 156-week minimum-duration rule
is reachable within the fixture.
